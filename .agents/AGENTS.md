# DriveOS Custom Workspace Rules

## Green Gradient Styling Directive
- **Brand Green Gradient Default**: All primary buttons, CTAs (`AI Assistant`, `New Deal`, `Restock Order`, `Tambah Kendaraan`, `Kirim Kampanye`, `Buka`), headline text highlights, level progress bars (age segment, funnel conversion, brand distribution), and ambient background orbs MUST use the Brand Green Gradient system derived from design system token `#4B8E55` (`linear-gradient(135deg, #33613A 0%, #4B8E55 55%, #6BA374 100%)`).
- **Standard Bar Graphs**: Keep standard bar graphs clean with standard solid green fill (`bg-[#4B8E55]`).
- **Browser Screenshot Validation**: Whenever analyzing browser screenshots or UI components, automatically ensure all green buttons, text accents, and level bars render with brand green gradient styling.
